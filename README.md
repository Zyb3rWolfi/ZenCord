# ZenCord

A little Discord API wrapper I've been developing as a university student, designed to give me hands-on experience with both Python and the complexities of real-time communication in bot development.

## Getting Started

These instructions will give you a copy of the project up and running on
your local machine for development and testing purposes. See deployment
for notes on deploying the project on a live system.

### Prerequisites

Currently no Prerequisites are required

### Installing

All you have to do is download the repo, move it to the project folder and import from wrapper.client.
